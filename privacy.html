Privacy Policy

rclone Drive Connection · Last updated October 27, 2026

Who uses this app

Only the owner of this site, with their own Google account. It is a personal tool and is not offered to anyone else.

What it can access

After the owner signs in, the app can see, upload, download and organize files in the owner's own Google Drive. It uses this access only to copy files the owner chooses between their computer and their Drive, and to check that uploads arrived intact.

What is collected

Nothing. No personal data, Drive content or usage data is collected, stored on any server, sold, shared, or used for advertising. The sign-in token is stored only on the owner's own computer.

Google API data

This app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Changes

Any changes to this policy will be posted on this page.
